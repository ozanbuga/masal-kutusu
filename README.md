# Masal Kutusu - Türk Masalları Derlemesi

Bu proje, Türk halk anlatı geleneğine ait masalları modern web standartlarıyla dijital bir okuma deneyimine dönüştüren tek sayfa web uygulamasıdır (SPA).

## Özellikler
* 8 farklı anonim Türk masalı.
* Anlık arama ve kategoriye göre filtreleme.
* Gece modu (Dark Mode) desteği.
* Dinamik metin boyutu ayarlama.
* Harici kütüphane veya çerçeve (framework) kullanılmadan, tamamen saf (Vanilla) HTML, CSS ve JavaScript ile geliştirilmiştir.
* Tamamen çevrimdışı (offline) çalışabilir.

## Proje Nasıl Açılır?
1. Bu depodaki tüm dosyaları bilgisayarınıza indirin.
2. Klasörün içerisindeki **`tek.html`** dosyasını bulun.
3. Dosyaya çift tıklayarak herhangi bir modern web tarayıcısında (Google Chrome, Firefox, Edge, Safari vb.) çalıştırabilirsiniz.
